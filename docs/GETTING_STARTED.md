# Démarrage

## Installation

```bash
npm install
npm run start:local
```

Puis ouvrir <http://127.0.0.1:8787/>.

## Premier parcours

Le tableau de bord propose une recherche guidée, l’accès aux résultats et l’import d’une annonce. Aucun compte ni clé API n’est requis pour utiliser le parcours local.

Pour enrichir les requêtes et les analyses, ouvrir **Options**, choisir un fournisseur IA et saisir une clé API. Cette configuration reste locale au navigateur.

## Vérification

```bash
npm test
npm run build
```
