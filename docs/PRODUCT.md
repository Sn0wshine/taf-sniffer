# Produit

Taf Sniffer est un outil de tri et de décision pour la recherche d’emploi, pas un job board supplémentaire.

## Principes

- Le métier, la zone et les critères de l’utilisateur priment sur un profil prédéfini.
- Le mode local reste utile sans clé API.
- L’IA enrichit les requêtes et l’analyse, mais ne remplace pas les garde-fous ni la vérification humaine.
- Les signaux spécialisés sont contextuels et ne doivent pas polluer les recherches génériques.
- Les sources externes sont faillibles ; l’import manuel est une voie officielle.
