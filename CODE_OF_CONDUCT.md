# Code de conduite

Nous voulons une communauté accueillante, professionnelle et inclusive. Les échanges doivent rester respectueux, factuels et centrés sur le code, la documentation ou l'expérience utilisateur.

Les comportements intimidants, discriminatoires, harcelants ou offensants ne sont pas acceptés. Les mainteneurs peuvent modérer ou fermer une contribution qui ne respecte pas ces règles.
